CTRL QUICK COMBOS — press CTRL, get C / B

Holding the rail's CTRL latch (or the visionOS cluster's) raises a C / B
strip over the key: one tap sends Ctrl+C or Ctrl+B, no keyboard needed.

- CTRL then C at a shell prompt: the line aborts with ^C, latch releases.
- Mash CTRL: the strip follows the latch every time, never sticks.
- With agent chips on screen, the strip sits on top of them, tappable.

IPHONE LOCKED RETURN — keep RET on the rail with the keyboard closed

Locking the software keyboard on iPhone adds RET after the arrow keys.
iPhone Air keeps RET, padlock, and TMUX together; narrower phones move
TMUX to its top-right button while locked.

- Hold the keyboard key on iPhone Air: RET appears, nothing clips.
- Press RET: it sends Return while the keyboard stays locked shut.
- Unlock: the previous rail returns, with no duplicate TMUX.

LOCKED DICTATION — use the mic with the software keyboard closed

The KEYBOARD LOCKED tip carries a mic, so a phone with no physical keyboard
can still dictate while the keyboard is locked.

- Tap the mic: LISTENING replaces the tip; STOP types the transcript
  without pressing Return, CANCEL types nothing.
- The mic latches immediately during the permission prompts; tapping it
  again cancels the pending attempt.

FILE VIEWER SELECTION — select and copy like a document

Code files and git diffs are one selectable surface. Line numbers and diff
gutters never come along: code copies as code, a diff as a real unified
diff (+/- prefixes, @@ headers).

- Drag a selection across several lines, Copy, paste: no line numbers.
- Copy across a hunk header in DIFF: pastes as an applicable diff.
- Rendered Markdown keeps its layout; the rail's SELECT chip swaps in raw
  source for cross-line selection, DONE returns.
- Scroll a big file while a change lands host-side: no jump to the top.

The viewer also finds the right directory on mosh hosts — it asks over its
own SSH connection instead of falling back to your home directory.

- mosh host, pane in a git worktree, + TAB ▸ File Viewer: the tree roots at
  that project, and pressed relative paths resolve inside it.

KEYBOARD LOCK, FINDABLE — a named action in the ⋯ menu

"Lock Keyboard Closed" / "Unlock Keyboard" is the first item in the
terminal's ⋯ menu, and ⋯ is now present at every window width.

- Full-screen iPad/iPhone: ⋯ sits beside DETACH and locks the keyboard.
- While locked, terminal taps must not raise the keyboard; rail and
  hardware keys keep typing.
- Wide windows: ⋯ carries ONLY the lock — no duplicate A−/A+, + TAB, FILE,
  MERGE, DETACH. Vision Pro has neither ⋯ nor the lock.

PRESSED LINKS AND PATHS ARE EDITABLE — AND STOP EATING THE LINE ABOVE

The link/path confirmation sheet shows its target in an editable field, and
OPEN / ⌗ VIEWPORT / ▤ VIEW / COPY act on what the sheet shows. A wrapped
sentence glued to a path ("…the file./etc/hosts") is trimmed to the path.

- Long-press a path on a wrapped line: PATH reads /etc/hosts.
- Edit the field: host line, REACH row, and title follow live; clearing it
  hides the action chips.
- Real paths are untouched: ./src/main.rs, ~/notes/todo.md, src/app.ts:42.

CHIP TAILS IN LANDSCAPE — no smear under the bottom-rail buttons

A phone in landscape printed a tail of chip fill through the home-indicator
strip under every bottom-rail button.

- iPhone landscape, + TAB ▸ File Viewer: each rail button is a clean square
  with rail ground below it. Same for a ⌗ viewport rail, light and dark.
- Portrait, and chips elsewhere (deck rail, UMD, sheets), look as before.

FILE VIEWER DRAWER SHADOW IN LIGHT — the tree reads as a lifted panel

In the light appearance the tree drawer's drop shadow was a heavy black
smudge over the near-white screen. It is now a cooler, weaker cast plus a
tight edge shadow, so the drawer separates without muddying the ground.

- Light appearance, narrow window (iPhone, or a narrow iPad window),
  + TAB ▸ File Viewer: the open drawer sits above the content screen with
  a soft cool shadow, not a grey wash.
- Slide it open and closed: the shadow follows the animation cleanly.
- Dark appearance: unchanged.
