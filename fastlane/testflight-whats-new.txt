NEW IN 1.3.0
• HERDR BACKEND — Host Settings ▸ Backend switches a host between TMUX and HERDR (herdr 0.7.5+): one deck tile per herdr session, HRDR shortcut panel, FILE attach/drop, MENU for herdr's pane menu, long-press a divider to resize a split, Claude Code HISTORY + JUMP.
• MIXED tmux + herdr ON ONE HOST — each refresh quietly asks the other multiplexer whether it has sessions; when it does the host rail offers "+ HERDR · 3" (long-press to stop being asked). Accept and its sessions join the wall, herdr tiles in a light purple chassis. Backend is now a check selection — tick tmux, herdr, or both, with a "New sessions run on" choice. New Session, the Open Shell / Open Agent Shortcuts, the Host widget, and Add Host ▸ BIND all gain a Backend picker on those hosts.
• SELECT TEXT — long-press, double-tap, or secondary-click terminal text on either backend: SELECT / SELECT ALL / PASTE at the gesture, selection clamped to the pane you pressed, floating COPY / SELECT ALL / DONE beside it.
• KEEP ALIVE IN BACKGROUND (iPhone/iPad) — Host Settings ▸ Monitoring, off by default. Leaving no longer drops that host at once, and iOS can wake the app later, so a turn ending after you left can still notify you.
• AGENT ALERTS — now fire for the session you walked away from (the one case that used to stay silent). Notification permission is asked while the app is on screen.
• VISION PRO GLASS — Settings ▸ Appearance adds GLASS beside SYSTEM / LIGHT / DARK, live across deck, terminals, forms, popovers. Typing under GLASS repaints only changed rows.
• TERMINAL TITLE BAR (iPad) — the system bar is replaced by the app's own slim rail.
• FILE VIEWER — its own tabs, ◂ ▸ browse history, DIFF stays selected across files, and text size via A− / A+ on the ▤ tab's rail or by pinching (remembered, applies to every ▤ tab).
• GUIDE — an illustrated field manual of the tab's gestures, on the title rail.
• Window tabs drag to reorder. Open Source Licenses in Settings ▸ About. Under mouse reporting each tap reaches the remote immediately. The STOP chip is gone — use ESC. TMUX / HRDR is no longer drawn twice.
• Every surface was rewritten on UIKit, so anything that differs from 1.2 is worth reporting.

PLEASE TRY
1. Add your own host (key or password) — did the wall probe everything?
2. Attach two sessions in separate windows, type in both. Merge one in as a tab, move it back out; it must not reconnect.
3. On a herdr host, switch backend both ways, then attach, split, close a pane, and work through the HRDR panel.
4. Long-press / double-tap / right-click terminal text on both backends, and copy from one pane of a split.
5. Open a file viewer tab, resize a long code file and a README with A− / A+ and by pinching, then open another file — it should arrive at the size you chose.
6. Turn Keep alive in background on for one host, attach a Claude Code / Codex / Pi session, start a turn, and leave the app. Did the alert arrive, and how long after?
7. Vision Pro: switch to GLASS and type fast in a busy session, then compare with DARK.
8. On a host running BOTH, accept the rail's "+ HERDR" (or "+ TMUX") chip and check both backends' tiles appear and attach to the right thing — especially with the same session name on both. Long-press to dismiss, then re-enable from Host Settings ▸ Backend.
9. On that host, create sessions on each backend from New Session ▸ Runs on, then point a widget and an Open Agent Shortcut at each backend.
10. Tick BOTH backends in Host Settings, switch "New sessions run on" back and forth — both must stay ticked. Then bind a machine from Add Host ▸ BIND with both ticked.

KNOWN
• Background wake timing is iOS's call — minutes or tens of minutes — and nothing arrives if Background App Refresh is off for Multiplex.
• If iOS terminated the app rather than suspending it, the first background check after relaunch only establishes a baseline; the next one can alert.
