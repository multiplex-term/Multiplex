NEW SINCE 1.3.0
• FILE VIEWER AND VIEWPORT BARS FLOAT BELOW THE WINDOW (Vision Pro) — the bottom bars of ▤ File Viewer and ⌗ viewport tabs used to sit inside the window, where their end buttons fought the window's resize corners. They now float outside the window as glass bars: the File Viewer keeps its controls in a row above the familiar window row (one CLOSE now, not two), and the viewport gets three compact clusters — back/reload, the address with its NET/LAN/VIA badge, and SYSTEM/CLOSE. The bars keep their own size while the window resizes freely around them. iPad is unchanged.
• MARKDOWN IMAGES SHOW ON A PRESS — in a rendered README the ⟨image: …⟩ placeholder is now a link. Press it and the picture appears right there in the document, sized to the text column; press the caption again to put it away, or tap the picture to open it full-screen with zoom. An image hosted on the web goes through the usual link confirmation instead. Nothing is fetched until you press.
• TMUX + MOSH FIXES — TMUX split shortcuts no longer type `%` on iPad, and File Viewer starts in the current tmux or herdr pane directory.
• SELECT BLOCK STAYS WHERE YOU PRESSED — the SELECT / SELECT ALL / PASTE block and the SELECT TEXT bar could drift up (by roughly a keyboard height, or clean off the screen) on mosh tabs and in scrolled-back terminals. Two placement bugs fixed; both bars now anchor to the visible screen beside your press or selection.
• MOSH TABS NO LONGER GROW A JUNK SCROLL AREA — mosh syncs one live screen (its protocol has no scrollback), but the app was archiving stale frames above it on every keyboard show/hide, breaking the herdr layout into stacked duplicates. Mosh tabs now hold exactly the live screen, like mosh itself.
• SELECT TEXT WITH A SECOND CLIENT ATTACHED — with another differently sized client on the same session (say a laptop `herdr attach` beside your phone), tmux and herdr resize their shared screen to whoever acted last. Select Text used to measure the pane mid-move and could highlight the wrong region; it now waits for the geometry to settle before clamping.
• RESTORE PURCHASES FIXED ON TESTFLIGHT — TestFlight's App Store backend often rejects the restore sync (the `SKInternalErrorDomain error 14` some of you reported). Restore now double-checks your owned purchases directly when that happens, and the error message names something you can act on instead of a raw error code.
• FILE PATHS WORK IN SPLIT PANES — pressing a file path printed in a tmux or herdr split now works like it does full-width: a long path that wrapped at the pane border is stitched back together instead of opening a truncated fragment, a match never picks up the neighbouring pane's text, and a relative path opens against the directory of the pane it was printed in — not whichever pane happened to be active.
• SMOOTHER STREAMING OUTPUT ON VISION PRO — the terminal used to schedule repaints on a 60 Hz clock while Vision Pro's display runs at 90 Hz, so fast-scrolling output (agent logs, builds, tails) advanced with a subtle beat. Repaints now align to the 90 Hz frame, so streaming text scrolls evenly. Typing was already on the fast path and is unchanged.
• METAL RENDERER OPTION — Settings → Terminal renderer adds a switch that draws terminal text on the GPU instead of CoreGraphics. Off by default; it takes effect for newly opened terminal windows. If you try it, we'd love to hear whether scrolling and typing feel better or worse on your device.
• OPEN FILE FROM SHORTCUTS — the new Open File action takes a host, remote file path, and optional line number, then opens that location read-only in a ▤ File Viewer tab. Tool-call references such as `Sources/App.swift:10-15` open at the first line and highlight the full range. Bare names and relative paths start from the host's first configured working directory, or home when none is configured.

In the File Viewer, check the last lines of a long file stay readable above the bar, and that back/forward, SOURCE/DIFF, TREE, REFRESH, A−/A+, and CLOSE all still work; in the viewport, tap the address to edit it and long-press it for Copy Address.
1. Open a README with screenshots in a ▤ file viewer tab and press its ⟨image: …⟩ placeholders — including one written `../assets/x.png`, one with a %20-escaped space in the filename, and one carrying a "title". Does the right picture appear, in the right place, at a sensible size?
2. Press the caption again to hide it, resize the tab and the text size (A− / A+) with pictures open, and scroll a long README with several of them open.
3. Press an image whose target is an https:// address — it must raise the link confirmation, not fetch the picture. Point one at an SVG or a PDF: it should say it can't draw it and offer OPEN FILE.
4. Press ordinary links in the same document: relative ones still navigate, and `docs/setup.md#install` now opens setup.md instead of failing.
5. On iPad SSH and mosh tabs, try both TMUX split shortcuts, then open File Viewer from non-home tmux and herdr panes. Splits must not type `%`; the viewer must start in each pane's directory.
8. In a tmux or herdr split, long-press a long file path that wraps at the pane border — the confirmation should show the whole path, and ▤ VIEW should open it. Then `cd` the two panes into different repos and press a relative path in the inactive one: it must open that pane's file.
6. In Shortcuts, run Multiplex's Open File with an absolute path and a line number. Then put `:10-15` after a path — it should center line 10 and wash lines 10 through 15. Also try a bare filename under the host's first configured working directory, and a path containing spaces or a colon.
7. If Restore Purchases failed for you before: Settings → Multiplex Pro → Restore Purchases. It should either restore your purchase or show a message that says what to check — never a bare `SKInternalErrorDomain` code.
