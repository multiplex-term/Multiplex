NEW SINCE 1.4.2
• iPhone landscape: the deck rail steps aside whenever it would leave the terminal under 390 pt, so SE-size phones get the full-width terminal (edge-swipe back to the deck).
• iPhone Duo: the shell follows the phone. On the closed display the chips stack beside the clock, on the camera's side in landscape, with no bars behind them. Folded as a book, the deck takes the left page and the terminal the right; folded as a laptop, the terminal sits above the fold and the deck below it. In both, the deck's HIDE control hands the whole display to the terminal and stays hidden when you rotate. The deck's + HOST / FAQ / SETTINGS stand beside the clock while the deck spans the display, and a viewer opened from the terminal takes the deck's column.
• iPhone Duo Split View: a half behaves like an iPhone (deck and terminal in turn, title bar on top); the half beside the clock keeps its chip column.
• Deck: the NO TMUX / NO HERDR tile's hint wraps across the tile instead of one character per line.
• iPad: Settings → Window mode → Single-window mode runs Multiplex in one window, as on iPhone — the deck beside the terminal, sessions as tabs. Off by default; takes effect the next time Multiplex launches. In a resized window the title row starts at the window's top edge, clear of the window controls, and the deck header and terminal title bar line up.
• Message box: a mic beside the send button dictates into the message (every platform, Vision Pro included). Words land as you speak; sending mid-sentence waits for the last words.
• Dictation: Settings → Voice input downloads a noise-reduction model that filters background noise out of the microphone before dictation hears it.
• Dictation listens through AirPods (or any Bluetooth headset mic) when one is connected, instead of the device's own microphone.
• Connect via Tailscale (experimental, Vision Pro included): SSH to a host through a Tailscale node built into Multiplex, no Tailscale app needed. Add a reusable auth key in Settings → Tailscale, then turn it on per host in Add Host. Mosh is unavailable on that path.
