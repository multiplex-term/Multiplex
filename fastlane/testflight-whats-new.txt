NEW SINCE 1.5.1
• iPhone Duo: the terminal's key row now runs the full width of the screen, under the side column, on both the closed and the open display, so the keys have more room. The keys at the ends of the row also stay clear of the screen's rounded corners.
• iPhone Duo: the bottom bar of a file viewer or web page tab stays clear of the rounded corners too, so CLOSE and the text size buttons are no longer clipped.
• iPhone Duo: on the closed display in landscape, the bars now match portrait, without the grey bands, and the session title sits at the left edge.
• iPhone: locking the keyboard no longer takes keys off a roomy key row. In landscape, ~ and / stay while the keyboard is locked, with RET added alongside them.
• Terminal: tapping a slash command such as /compact in an agent's input bar or command list no longer offers to open it as a file.
• File viewer: FIND searches the open file. Press FIND on the bar (or Command-F with a keyboard), type, and every match is marked, with a count; Return or the arrows step through them, and Command-G and Shift-Command-G step from the keyboard. It works on code, diffs and markdown, which is searched as rendered rather than switched to its source, and stays open as you pick other files from the tree.

2. Pick another file from the tree: the search should carry over. Try a diff and a README too, and Command-F with a hardware keyboard. On iPad, open a path from a terminal into the side panel, use FIND, then DONE: typing should go back to the terminal.
