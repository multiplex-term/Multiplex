Multiplex 1.1.0 — add a host by running one command and choose the model an agent launches with.

• Add Host now opens on BIND. Run “mpx bind” on a Mac or Linux machine, then enroll it from ASKING TO BIND on your local network or paste its payload through Universal Clipboard. MANUAL remains one tap away. In the normal connected flow, Multiplex creates the SSH key on Vision Pro and sends only its public half; an optional key passphrase keeps the stored key encrypted.
• Configure each host's Claude Code, Codex, and Pi model lists once in Host Settings, then choose a model from New Session, the Host widget, the Open Agent Shortcut, or the ASK prompt sheet. Free text remains available for models not in the list.
• Switch monitoring off for a host without deleting it. Multiplex stops automatic probes while terminal tabs you already opened keep running.
• Long-press a web or mail link in terminal output to inspect its resolved destination before opening it. Other schemes remain copy-only.
• The deck and widgets now show meaningful single-pane titles, and a tap reliably dismisses the terminal's long-press selection menu.
