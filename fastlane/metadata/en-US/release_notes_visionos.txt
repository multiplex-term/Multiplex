Multiplex 1.4.1 — links and paths open beside the terminal, the app speaks Traditional Chinese and Japanese, and Antigravity CLI and Hermes Agent join the agent roster.

• A confirmed web link or file path opens in a side panel hanging off the terminal window instead of a new tab — the terminal never changes size. Drag either edge to resize it, open another and it takes the first one's place, or press TAB to move it into a tab. Open File from Shortcuts lands there too.
• Traditional Chinese and Japanese: sheets, alerts, menus, the Guide and notifications are translated. Pick the language per app in Settings ▸ Multiplex ▸ Language — the LANGUAGE row in Multiplex Settings takes you there. The short key labels stay English.
• Antigravity CLI and Hermes Agent join the agent roster: both are detected in panes, each with its own chip strip, NEW SESSION launch with model and first prompt, and a place in widgets and Shortcuts. Hermes Agent runs the prompt, then reopens on that conversation.
• Copy a session's attach command: long-press a session tile and pick Copy Command for Handoff — the clipboard gets the line that attaches that very session from a terminal on the host machine itself, tmux and herdr alike.
