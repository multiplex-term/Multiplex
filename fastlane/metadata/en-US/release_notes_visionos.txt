Multiplex 1.3.0 — a smoked Glass appearance, herdr as an alternative to tmux, and text selection in any pane.

• Settings → Appearance adds GLASS beside System, Light, and Dark. One smoked spatial material grounds each window and sheet, the room stays visible behind the chassis, and the monitor hierarchy — screens darker than frames, tally red only on live state — survives intact. It shares Dark's terminal-theme selection and switches every open window live.
• Choose a session backend per host. Host Settings → Backend switches between tmux and herdr 0.7.5+: one deck tile per herdr session, its workspaces on the tile's spine, live miniatures, and agent state read from herdr itself. Attaching, merging, detaching, file attachment, shortcut panels, and agent history all work on either backend.
• Long-press or double-pinch terminal text for SELECT / SELECT ALL / PASTE right at the gesture. The selection stays inside the pane you looked at on split layouts, a floating bar carries COPY and DONE beside it, and pinches stop reaching the remote until you finish. On herdr tabs the block adds MENU, which opens herdr's own pane menu at that cell.
• Typing under GLASS keeps up. Each keystroke used to repaint the whole translucent pane over live glass; now only the rows that changed are redrawn, and the once-a-second agent check and gaze link-region rebuild pause while you type.
• The ESC / CTRL / TAB key cluster now sits wholly below the window instead of straddling its bottom edge, and the shortcut, Command Setup, and agent History popovers clear the rounded platter's corners.
• Agent alerts now reach you about the session you were last looking at — the one most likely to be running an agent, and the one that used to stay silent. Notification permission is asked while Multiplex is on screen instead of riding your first alert, and Host Settings → Monitoring adds a Keep alive in background switch, off by default, that holds an opted-in host's sessions and probing open for the extra running time the system grants after you leave.
• Drag window tabs into the order you want. The File Viewer gains tabs of its own — long-press a file in the tree to open it beside the first — plus ◂ ▸ browse history, and it keeps DIFF selected as you move between changed files.
• Every terminal's ⋯ menu leads to Guide, an illustrated field manual of that tab's gestures. Settings → About lists every open-source component in the binary with its full license text.
• The agent strip no longer carries STOP: press ESC in the key cluster to interrupt a turn.
• Rebuilt on UIKit throughout, for steadier typing, scrolling, and window handling.
