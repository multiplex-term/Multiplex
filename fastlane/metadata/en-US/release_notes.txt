Multiplex 1.0 — first release.

• The wall: every tmux session as a live monitor, before you attach
• A spatial window per session on Vision Pro; real scenes on iPad
• Tabs, merge, and split — shells stay connected while windows move
• Two hosts included free; Multiplex Pro unlocks unlimited hosts
• A custom tmux shortcut menu, with touch-native copy mode, in the Vision Pro UMD and iPad/iPhone terminal chrome
• Touch and pointer clicks for mouse-aware terminal apps
• Multilingual system-keyboard and IME input, hardware keyboard support, and a dedicated Return key in the iPad terminal rail
• Start Claude Code, Codex, or Pi in a new tmux session with an optional per-host setup script and first prompt; detection across split panes and plain SSH shells, foreground-aware helpers, synced per-host chip placement and custom commands, Claude Code/Codex Pro alerts, and Claude Code prompt history with jump-back-to-message (Pro)
• mosh built in (Pro): sessions survive sleep, roaming, and IP changes
• File attachments from Photos or Files, camera capture on iPad, and terminal drag-and-drop
• Home Screen widgets — a per-host monitor and a fleet wall with last-known session frames; tap to attach a shell or launch an agent (iPadOS 17, visionOS 26)
• Shortcuts & Siri: "Open Shell" and "Open Agent" (with working-directory and setup-script pickers plus an optional first prompt) for any host, plus a multiplex:// URL scheme for automation
• Light & dark appearance that follows your device, a terminal theme per appearance, built-in themes, Pro custom themes, iCloud Keychain host sync
• Optional App Lock: require Face ID, Touch ID, or Optic ID when Multiplex opens or returns from the background
