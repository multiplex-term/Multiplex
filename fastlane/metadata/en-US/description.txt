Multiplex is a terminal for people who live inside remote tmux sessions — built native for Apple Vision Pro and iPad.

THE WALL
Hosts probe concurrently and every tmux session appears as a live monitor: its actual last lines, a spine segment per window, and a red LIVE tally while you're attached. You see everything running across your fleet before you ever attach. An unreachable host shows NO SIGNAL — reconnect in one tap.

A WINDOW PER SESSION
Attach opens the session in its own window. On Vision Pro that means real spatial windows — build logs above your editor, a server dashboard across the room. On iPad every terminal is a real scene: Stage Manager, Split View, external displays. Merge windows into tabs and split them back out — the SSH connection, buffer, and scrollback move with the tab, so shells never drop.

BUILT FOR AI AGENT SESSIONS
Start a tmux session with Claude Code, Codex, or Pi — optional setup script and first prompt included — in one step. Multiplex spots all three across every pane, right on the wall. Helper chips follow the foreground agent — split tmux pane or plain SSH shell — so commands go to the process receiving your keystrokes. Everyone gets one-tap command chips each day: stop, clear/compact/resume, model and thinking switches, and more. Each host remembers its own setup across your devices — move built-ins between the bar and More, add ordered custom commands (single or multiline), and share them across all three agents. Pro removes the daily command limit, adds Claude Code/Codex notifications when an unwatched session finishes a turn, asks a question, or waits for permission, and opens a Claude Code session's prompt history — full text from Claude's own session file, even where the TUI truncates — with one tap to jump the transcript to any message. In an SSH-backed tmux tab, attach files from Files or Photos (or the iPad camera), or drag a file onto the terminal: Multiplex uploads it to the session's working directory and types the remote path — ready for the agent.

WIDGETS & SHORTCUTS
Put a host on your Home Screen: a wall tile in miniature — last-known session frames with an honest SEEN stamp — plus SHELL and AGENT keys that jump straight into a connection; a fleet widget shows every host at a glance. Shortcuts and Siri can open a shell on any host or launch Claude Code, Codex, or Pi in a chosen working directory — setup script and first prompt included — and a multiplex:// URL scheme powers your own automations.

MOSH BUILT IN
With Pro, switch a host to mosh and the session survives sleep, roaming, and IP changes — a native Swift mosh client, no companion app. Made for a headset that suspends and an iPad that hops networks.

A REAL TERMINAL
Full xterm-256color emulation, multilingual system-keyboard input, touch and pointer clicks for mouse-aware TUIs, hardware keyboards, live PTY resize, and a built-in menu for everyday tmux commands — windows, panes, copy mode, rename, zoom. Copy mode keeps selection native; Done exits. System, Light, Dark, and Vision Pro’s smoked Glass switch the whole chassis. Glass shares Dark’s terminal theme — ten built-ins included. Pro adds a custom theme editor for background, text, cursor, and all 16 ANSI colors.

PRIVATE BY DESIGN
Hosts, agent-command setups, and secrets sync between your devices through iCloud Keychain, end-to-end encrypted. Nothing touches our servers — there are none. No account, no analytics, no tracking.

MULTIPLEX PRO
One purchase, no subscription: unlimited hosts, mosh, agent notifications, the unmetered agent command strip, and custom themes — on all your devices. The free app includes two hosts, the full spatial experience, and 10 agent-command chip taps each day.

WHAT YOU NEED
A remote host you can reach over SSH (password or OpenSSH ed25519/RSA key). The live wall and persistent session features need tmux 1.8 or newer; plain SSH shells work without tmux. mosh needs mosh-server on the host. Works with any POSIX login shell.
