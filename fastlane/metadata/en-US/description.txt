Multiplex is a terminal for people who live inside remote tmux sessions — built native for Apple Vision Pro and iPad.

THE WALL
Your hosts probe concurrently and every tmux session appears as a live monitor: its actual last lines, one spine segment per window, and a red LIVE tally while you're attached. You see everything running across your fleet before you ever attach. An unreachable host shows NO SIGNAL — reconnect is one tap.

A WINDOW PER SESSION
Attach opens the session in its own window. On Vision Pro that means real spatial windows — build logs above your editor, a server dashboard across the room. On iPad every terminal is a real scene: Stage Manager, Split View, external displays. Merge windows into tabs and split them back out — the SSH connection, buffer, and scrollback move with the tab, so shells never drop.

BUILT FOR AI AGENT SESSIONS
Multiplex spots Claude Code, Codex, and Pi across every pane in your sessions, right on the wall. Helpers follow the foreground agent in a split tmux pane or a plain SSH shell, so commands always go to the process currently receiving your keystrokes; a plain shell also carries its own NEEDS YOU state in the terminal chrome because it has no wall tile. Everyone can try the one-tap command chips each day (stop, clear/compact/resume actions, model and thinking switches, and more). Each host remembers its own setup across your devices: move every built-in between the bar and More, then add ordered custom commands — single or multiline, with Auto Submit and bar placement under your control, and optional sharing across all three agents on that host. Pro removes the daily command limit, adds Claude Code/Codex notifications when an unwatched tmux session or plain shell finishes a turn, asks a question, or waits for permission, and opens a Claude Code session's prompt history — read from Claude's own session file, full text even where the TUI truncates — with one tap to jump the transcript back to any message. In an SSH-backed tmux tab, use the FILE menu to attach from Files or Photos (or take a new photo on iPad), or drag a file onto the terminal. Multiplex uploads it to the session's working directory and types the remote path for you — ready for the agent to read.

MOSH BUILT IN
With Pro, switch a host to mosh and the session survives sleep, roaming, and IP changes — a native Swift mosh client, no companion app. Made for a headset that suspends and an iPad that hops networks.

A REAL TERMINAL
Full xterm-256color emulation, multilingual system-keyboard input, touch and pointer clicks for mouse-aware TUIs, hardware keyboard support, live PTY resize, and a built-in menu for the tmux commands you use most: new and switch windows, split and navigate panes, copy mode, rename, and zoom. Copy mode keeps text selection native and adds a clear Done action. Seven built-in color themes are included. Pro adds a custom theme editor for background, text, cursor, and all 16 ANSI colors.

PRIVATE BY DESIGN
Hosts, agent-command setups, and secrets sync between your devices through iCloud Keychain, end-to-end encrypted. Nothing touches our servers — there are none. No account, no analytics, no tracking.

MULTIPLEX PRO
One purchase, no subscription: unlimited hosts, mosh, agent notifications, the unmetered agent command strip, and custom themes — on all your devices. The free app includes two hosts, the full spatial experience, and 10 built-in or custom agent-command chip taps each day.

WHAT YOU NEED
A remote host you can reach over SSH (password or OpenSSH ed25519/RSA key). The live wall and persistent session features need tmux 1.8 or newer; plain SSH shells work without tmux. mosh needs mosh-server on the host. Works with any POSIX login shell.
