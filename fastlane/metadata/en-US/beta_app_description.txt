Multiplex is a spatial SSH terminal built around remote tmux, with herdr as a per-host alternative — native for Apple Vision Pro, iPad, and iPhone.

The deck is a live wall: every host probes concurrently, and each session renders as a tile showing that session's real last screen lines. Tap a tile to attach and the session opens in its own window — spatial on Vision Pro, a Stage Manager scene on iPad, a full-screen pane on iPhone. Windows merge into tabs and split back out without dropping the shell. In HERDR mode one tile is one herdr session, its workspaces become the tile's spine, and agent state comes from herdr itself.

Multiplex also spots Claude Code, Codex, and Pi running in a pane and puts a command strip under the terminal. Multiplex Pro adds alerts when an unwatched agent finishes a turn or asks a question, Claude Code prompt history with one-tap jump to any message, mosh, unlimited hosts, and a custom terminal theme editor.

WHAT YOU NEED
- A host you can reach over SSH (password, or an OpenSSH ed25519/RSA key).
- tmux 1.8+ or herdr 0.7.5+ on that host for the wall and persistent sessions. Plain SSH shells work without either, but have no tiles.
- mosh-server on the host if you want to try the mosh transport (Pro).

WHERE THINGS ARE
- + HOST on the deck adds a host; probing starts immediately.
- Settings → Appearance switches the chassis live; Vision Pro adds GLASS beside SYSTEM, LIGHT, and DARK.
- Host Settings → BACKEND switches a host between TMUX and HERDR. → MONITORING also holds Keep alive in background, off by default.
- + NEW SESSION starts a persistent session, or launches an agent with an optional setup script, model, and first prompt. Widget and Shortcut launches work on both backends and can land inside an existing session.
- TMUX (bottom bar on Vision Pro, key rail on iPad/iPhone, top-right on narrow iPhones) sends everyday tmux commands. On herdr tabs the key reads HRDR and sends herdr's own.
- Long-press, double-tap, or secondary-click the terminal for SELECT / SELECT ALL / PASTE on either backend; the selection stays inside that pane. herdr tabs add MENU, which opens herdr's own pane menu at that cell.
- FILE uploads from Photos, Files, or the camera into the active pane's working directory and types the remote path without pressing Return. Dragging a file in does the same.
- + TAB → File Viewer browses host files and git diffs; long-press a path in terminal output to open that file beside the session.
- A terminal's GUIDE chip is an illustrated field manual of the gestures for that tab.
- DETACH closes the window; the remote session keeps running and its tile stays on the wall.
- Home Screen widgets show a host's last-known sessions plus SHELL and AGENT keys; Shortcuts and Siri can open a shell, show a remote file at a line or line range, or launch an agent.

Hosts, agent command setups, and secrets sync between your devices through iCloud Keychain, end-to-end encrypted. There is no Multiplex server, no account, and no analytics.

WORTH REPORTING
Anything that drops a connection, loses keyboard focus, misplaces or resizes a window, or garbles what the terminal draws — with your device, OS version, and what you were doing at the time. Screenshot feedback inside TestFlight reaches the developer directly.
