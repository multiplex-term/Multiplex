Multiplex 1.3.1 — pictures in your READMEs, file paths that work in split panes, and a cleanup pass over selection, scrolling and mosh.

• In a rendered README the “image: …” placeholder is now a link: press it and the picture appears right in the document, sized to the text column — press the caption to hide it, or tap for full-screen zoom. Web-hosted images stay behind the link confirmation, which now offers a docked ⌗ viewport as well as the browser, and nothing is fetched until you press.
• File paths work in split panes. A path wrapped at a pane border is stitched back together, a match never picks up the neighbouring pane's text, and a relative path resolves against the pane you pressed.
• Shortcuts gains Open File: a host, a remote path, and an optional line — Sources/App.swift:10-15 opens read-only in a ▤ File Viewer tab with the range highlighted. Pressed paths in the terminal carry line ranges the same way.
• The key rail runs to the window's bottom edge on iPad instead of floating above the home-indicator strip — more daylight below the keys, in iPhone landscape too.
• Selection stays where you pressed. The SELECT block and the SELECT TEXT bar no longer drift upward on mosh tabs or in scrolled-back terminals, and with a second client attached the selection waits for the shared geometry to settle.
• mosh tabs keep one screen — the junk scroll area that stacked stale layouts above the live screen is gone.
• The tmux split shortcuts no longer type a stray % on iPad, and the File Viewer opens in the pressed pane's working directory on tmux and herdr alike.
• Every connection now verifies the server's SSH host key against the fingerprints recorded for that host — from Bind Host, a key pasted into Add Host → Host key, or pinned on first connection. Host Settings → Host key lists what's recorded.
• Settings → Terminal renderer can draw terminal text on the GPU with Metal — off by default, applied to newly opened terminal windows.
• Restore Purchases recovers when the App Store's restore sync fails, and its errors now name something you can act on.
