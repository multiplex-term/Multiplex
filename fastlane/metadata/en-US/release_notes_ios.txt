Multiplex 1.1.0 — add a host by running one command, choose the model an agent launches with, and dictate from the key rail.

• Add Host now opens on BIND. Run “mpx bind” on a Mac or Linux machine, then enroll it over the local network, scan its QR code, or paste its payload. MANUAL remains one tap away. In the normal connected flow, Multiplex creates the SSH key on your device and sends only its public half; an optional key passphrase keeps the stored key encrypted.
• Configure each host's Claude Code, Codex, and Pi model lists once in Host Settings, then choose a model from New Session, the Host widget, the Open Agent Shortcut, or the ASK prompt sheet. Free text remains available for models not in the list.
• With a physical keyboard connected, the key rail now offers Dictation. Multiplex waits for the final transcript, types it as one line, and never presses Return; recognition stays on device wherever the language supports it.
• Switch monitoring off for a host without deleting it. Multiplex stops automatic probes while terminal tabs you already opened keep running.
• Long-press a web or mail link in terminal output to inspect its resolved destination before opening it. Other schemes remain copy-only.
• The deck and widgets now show meaningful single-pane titles. Taps reliably dismiss the terminal's selection menu, and held software-keyboard Backspace repeats again.
