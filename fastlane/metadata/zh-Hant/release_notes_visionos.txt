Multiplex 1.4.2 — 自訂按鍵順序、連接使用 fish 或 csh 的主機，遠端網頁位址的開啟方式也更可靠。

• 排列按鍵：開啟終端機的三點選單，拖曳按鍵調整順序，也可移到標題的另一側，再按 DONE。RESET 可還原預設順序。排列方式會儲存在這部裝置，並套用到所有標籤頁。
• 現在可連接使用 fish 或 csh 的主機：Multiplex 會透過 sh 執行遠端指令，無須變更主機的登入 shell，即可測試連線、重新整理 Deck、建立與連接工作階段。若探測仍失敗，錯誤訊息會附上 shell 診斷資訊。
• CTRL 面板不再重疊：長按 CTRL 時，Key Commands 會取代已開啟的 C / B 快速鍵面板，不會同時留下兩個面板。
• 內嵌瀏覽器可辨識各種寫法的 IPv4 映射 IPv6 位址。映射的 localhost 會透過 SSH 主機開啟，不會連到這部裝置；區域網路位址也會顯示正確的網路範圍標籤。
• Guide 已從控制列移至終端機的三點選單。
