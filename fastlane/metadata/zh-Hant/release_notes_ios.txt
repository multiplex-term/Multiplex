Multiplex 1.4.1 — 在 iPad 上連結與路徑會在終端機旁邊開啟，App 支援繁體中文與日文，Antigravity CLI 與 Hermes Agent 加入代理程式名單。

• 在 iPad 上，確認過的網頁連結或檔案路徑會在窗格旁邊的側邊面板開啟，而不是新的標籤頁 — 終端機的大小完全不變。拖曳邊緣可調整寬度，再開啟另一個會取代前一個，按 TAB 則把它移到標籤頁。捷徑的「開啟檔案」也會在這裡開啟。
• 繁體中文與日文：表單、提示、選單、GUIDE 與通知都已翻譯。在「設定 → Multiplex → 語言」中為 App 個別選擇語言 — Multiplex 設定裡的 LANGUAGE 列會帶你前往。簡短的按鍵標籤維持英文。
• Antigravity CLI 與 Hermes Agent 加入代理程式名單：兩者都會在窗格中被偵測，各有自己的指令列、可從 NEW SESSION 指定模型與第一則提示啟動，也出現在小工具與捷徑中。Hermes Agent 會先執行提示，再回到該對話。
• 複製工作階段的連接指令：長按工作階段方塊並選擇「複製交接指令」— 剪貼簿會得到能從主機本身的終端機連接該工作階段的那一行，tmux 與 herdr 皆適用。
