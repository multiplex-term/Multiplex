Multiplex 1.3.1 — README 裡的圖片、在分割窗格中也管用的檔案路徑，以及選取、捲動與 mosh 的整理。

• 在已算繪的 README 中，「image: …」預留位置現在是連結：按一下，圖片就直接顯示在文件裡，寬度配合文字欄 — 按圖說可隱藏，輕點可全螢幕縮放。網路圖片仍在連結確認之後，確認頁現在除了瀏覽器也提供停靠的 ⌗ 檢視區，按下前不會抓取任何東西。
• 檔案路徑在分割窗格中也能用。折在窗格邊界的路徑會重新接合，比對不會拾取鄰近窗格的文字，相對路徑則以你按下的窗格為基準解析。
• 捷徑新增「開啟檔案」：主機、遠端路徑，加上選填的行號 — Sources/App.swift:10-15 會在 ▤ 檔案檢視器標籤頁中唯讀開啟並標示範圍。終端機中按下的路徑也同樣帶著行範圍。
• 在 iPad 上按鍵列會延伸到視窗底部，而不是浮在主畫面指示器上方 — 按鍵下方更清爽，iPhone 橫向也一樣。
• 選取會留在你按下的位置。SELECT 區塊與 SELECT TEXT 列在 mosh 標籤頁或已向上捲動的終端機中不再向上飄移，有第二個用戶端連接時，選取會等待共用的幾何狀態穩定。
• mosh 標籤頁只保留一個畫面 — 把過時版面堆在即時畫面上方的多餘捲動區已經移除。
• tmux 分割快速鍵在 iPad 上不再多打一個 %，檔案檢視器在 tmux 與 herdr 上都會於按下的窗格工作目錄開啟。
• 每次連線都會用該主機記錄的指紋驗證伺服器的 SSH 主機金鑰 — 來自 Bind Host、貼進「新增主機 → 主機金鑰」的金鑰，或第一次連線時釘選的金鑰。「主機設定 → 主機金鑰」列出已記錄的內容。
• 「設定 → 終端機繪製器」可用 Metal 在 GPU 上繪製終端機文字 — 預設關閉，套用到新開啟的終端機視窗。
• 「回復購買項目」在 App Store 回復同步失敗時能夠復原，錯誤訊息現在會指出你能採取的行動。
