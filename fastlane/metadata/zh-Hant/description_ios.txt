Multiplex 是為長期活在遠端持久工作階段裡的人打造的終端機 — 開放原始碼，專為 iPhone 與 iPad 原生打造。

監控牆
所有主機同時探測。每個工作階段都是一面即時監視器：顯示它真正的最後幾行畫面、每個視窗一段脊線、連接中時亮起紅色 LIVE。連接前先看清整支艦隊；NO SIGNAL 一按即重新連線。跑 tmux，或把主機切到 herdr — 每個工作階段一個方塊、工作區排在脊線上、Agent 狀態直接來自 herdr。

工作階段就在你需要的地方
在 iPad 上，連接會把每個工作階段開在真正的場景中，可用於幕前調度、分割顯示與外接顯示器。把視窗合併成標籤頁，再拆回去 — SSH 連線、緩衝區與捲動記錄都跟著標籤頁走，Shell 永遠不會斷。在 iPhone 上，監控牆與終端機共用一個自適應的全螢幕 Shell。

為 AI Agent 工作階段而生
一步就能啟動 Claude Code、Codex、Pi、Grok Build、Antigravity CLI 或 Hermes，可選擇設定指令碼、模型與第一個提示。Multiplex 能在每個窗格中認出這六種 Agent，輔助按鈕會跟著前景的 Agent 走，指令因此送到真正接收你按鍵的程序 — 重新排列、加入自己的按鈕，每台主機都會在你所有裝置上記住這組設定。較長的提示交給訊息框：用自動修正與聽寫撰寫、附加照片或檔案，整段一次送出。在 tmux 與 herdr 標籤頁附加或拖放檔案：Multiplex 會上傳到窗格的工作目錄，並替你輸入遠端路徑。Pro 取消每日按鈕次數上限、在你沒盯著的回合結束或需要輸入時提醒你（tmux 上的 Claude Code、Codex 與 Grok Build；herdr 上則是 herdr 自己追蹤的每一個 Agent），並開啟 Claude Code 的提示歷史，一按就跳到對話記錄。

檔案與連結就在終端機旁邊
點一下終端機輸出中的連結或路徑，Multiplex 會先確認解析後的目標才開啟。檔案會在 ▤ 檔案檢視器中以唯讀方式開啟：程式碼、Markdown 預覽、圖片、PDF、聲音檔與 git 差異。網頁連結則可以開在內嵌的 ⌗ 檢視區，不必交給瀏覽器。在 iPad 上，兩者都會出現在窗格旁的側邊面板 — 終端機的大小完全不變 — 也可以移到標籤頁。

小工具與捷徑
把主機放到主畫面 — 最後已知的工作階段畫面、誠實的 SEEN 時間戳，加上直通連線的 SHELL 與 AGENT 鍵 — 或用艦隊小工具一眼看盡所有主機。捷徑與 Siri 可以開啟 Shell、以指定行或行範圍顯示遠端檔案，或在選定目錄啟動 Agent — 開新的工作階段，或進入既有的那個。multiplex:// URL scheme 可驅動你自己的自動化。

內建 mosh
有了 Pro，把主機切到 mosh，工作階段就能在睡眠、漫遊與 IP 變更後存活 — 原生 Swift mosh 用戶端，不需要配套 App。

連線統計
每台主機列上都有即時延遲指示；Pro 開啟完整面板，可逐台深入：往返、回應延遲、mosh 遺失與漫遊、重新連線與流量。僅在工作階段內測量；不會儲存，也不會離開這台裝置。

真正的終端機
完整的 xterm-256color 模擬、多語系系統鍵盤輸入、供滑鼠感知 TUI 使用的觸控與指標點擊、硬體鍵盤、即時 PTY 調整大小，以及內建的日常 tmux 指令選單 — herdr 標籤頁則有 herdr 自己的一組。按住 CTRL 開啟按鍵指令：軟體鍵盤按不出來的已儲存組合鍵（Shift+Enter、連按兩次 Ctrl-C、Option+Backspace 刪除一個字）與單行文字巨集，可自訂重複次數與保持開啟規則，並在你的裝置間同步。長按、點兩下或按右鍵，在任一後端進行限定於窗格內的文字選取。系統、淺色與深色會一起切換整個外框，各自保有自己的終端機主題 — 內建十個，Pro 再加上背景、文字、游標與全部 16 個 ANSI 顏色的編輯器。App 本身支援英文、繁體中文與日文。

開放原始碼，隱私即設計
整個 App — 終端機引擎、mosh 用戶端，全部 — 都以 Apache 2.0 開放原始碼，就在 github.com/multiplex-term/Multiplex。親自讀保管你金鑰的程式碼，或自己動手建置。主機、Agent 指令設定與密碼會透過 iCloud 鑰匙圈在你的裝置間同步，端對端加密。沒有任何東西會經過我們的伺服器 — 因為根本沒有伺服器。不需帳號、沒有分析、沒有追蹤。

MULTIPLEX PRO
一次購買、不需訂閱：無限主機、mosh、Agent 通知、連線統計面板、不計次的指令列、自訂主題，以及你所有裝置上的十二個按鍵指令。免費版包含兩台主機、完整的終端機、五個按鍵指令，以及每天 10 次 Agent 指令按鈕。

你需要什麼
一台可透過 SSH 連上的遠端主機（密碼或 OpenSSH ed25519/RSA 金鑰）。即時監控牆與持久工作階段需要 tmux 1.8+ 或 herdr 0.7.5+；一般 SSH Shell 兩者皆不需要。mosh 需要主機上有 mosh-server。
