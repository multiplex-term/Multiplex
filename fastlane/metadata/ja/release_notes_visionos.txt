Multiplex 1.3.1 — README の中の画像、ウインドウの下に浮かぶバー、そして選択・スクロール・mosh の整理。

• ▤ ファイルビューアと ⌗ ビューポートのタブの下部バーは、ウインドウの外に浮かんでリサイズの角を避け、ウインドウのサイズが変わっても大きさを保ちます。
• レンダリングされた README では「image: …」のプレースホルダがリンクになりました。押すと画像が本文の幅に合わせてその場に表示され、キャプションを押すと隠れ、タップで全画面ズーム。Web 上の画像はリンク確認の後ろに留まり、確認画面ではブラウザに加えてドックされた ⌗ ビューポートも選べます。押すまで何も取得しません。
• ファイルパスが分割ペインでも動作します。ペインの境界で折り返されたパスはつなぎ直され、隣のペインのテキストを拾うことはなく、相対パスは押したペインを基準に解決されます。
• ショートカットに「ファイルを開く」が加わりました：ホスト、リモートのパス、任意の行 — Sources/App.swift:10-15 が ▤ ファイルビューアのタブで読み取り専用で開き、範囲がハイライトされます。ターミナルで押したパスも同じように行範囲を運びます。
• 選択は押した場所に留まります。SELECT ブロックと SELECT TEXT バーは、スクロールバックしたターミナルや mosh タブでずれなくなり、2 つ目のクライアントがアタッチしているときは共有ジオメトリが落ち着くのを待ちます。
• mosh タブは 1 画面だけを保ちます — 古いレイアウトをライブ画面の上に積み上げていた不要なスクロール領域はなくなりました。
• ストリーミング出力がより滑らかに：再描画が 60 Hz のクロックではなく 90 Hz のディスプレイに揃い、高速でスクロールするテキストが均等に進みます。
• 長いスクロールは、パンを始めた位置に固定され、herdr のタブバーや tmux のステータス行へ流れていきません。
• ファイルビューアは、tmux でも herdr でも押したペインの作業ディレクトリで開きます。
• すべての接続で、サーバの SSH ホスト鍵をそのホストに記録された指紋と照合するようになりました — Bind Host から、「ホストを追加 → ホスト鍵」に貼り付けた鍵、または初回接続時にピン留めした鍵。「ホスト設定 → ホスト鍵」に記録内容が一覧されます。
• 「設定 → ターミナルレンダラー」で Metal を使い GPU 上にターミナルのテキストを描画できます — デフォルトはオフで、新しく開いたターミナルウインドウに適用されます。
• 「購入を復元」は App Store の復元同期が失敗しても回復し、エラーは対処できる内容を示すようになりました。
